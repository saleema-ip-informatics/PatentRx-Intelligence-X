# Patent source review checklist

Patent CN1202113C (Chinese original). The English machine translation is **supporting context**, not structural authority.

The abstract describes formulae I–III and bidentate/tridentate polypyridyl ligands, with chloride, thiocyanate, cyanide, bromide and iodide examples. The description discusses cis/trans and N/S linkage isomer issues. **Do not treat these broad classes as a verified exact molecular graph.**

Original drawings and selected example formulas must be inspected before adding any patent-derived SMILES. Track page, example number, ligand atom connectivity, metal-ligand bonding convention, formal charges, counterions, and stereochemical evidence. For ambiguity, record `NOT_ESTABLISHED` instead of guessing.
